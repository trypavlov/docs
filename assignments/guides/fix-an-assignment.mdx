---
title: "Fix an assignment that isn't right"
description: "Improve an assignment step by step, and what to do when a Book or a result looks wrong"
---

Expect to revise an assignment two or three times before it's right.

## Improve it step by step

<Steps>
  <Step title="Change one thing at a time">
    Edit the ask, plan it again, and compare the new plan with the old one.
  </Step>
  <Step title="Test on a small Book">
    Run it once on a small Book before you put it on a schedule or a larger Book.
  </Step>
  <Step title="Widen in steps">
    One small Book, then one segment or one owner, then the rest.
  </Step>
  <Step title="Plan it again when the data changes">
    An assignment plans against the sources, tables and fields that exist when it's planned. When a new one is added, plan the assignment again so it can use it.
  </Step>
  <Step title="Note what you changed">
    A line in your team's shared channel is enough.
  </Step>
</Steps>

## When something isn't right

| What you see | Likely cause | What to do |
| --- | --- | --- |
| The Book count is far higher than expected | A filter or an exclusion is missing | Add filters one at a time and watch the count. |
| The Book count is zero | Two filters contradict each other, or a value is spelt differently in the data | Remove the last filter and check the values on an account you know. |
| A field is missing from the filter list | It hasn't been imported | Send your Trig contact the field and where it lives. |
| The plan reads the wrong table or tool | The ask didn't name the source | Name the source in the ask. |
| Numbers don't match your own reports | The assignment's definition differs from yours | Write your definition into the ask, or point it at your own table or query. |
| Users appear as IDs instead of names | The assignment has no way to look the user up | Tell it which table maps the ID to a name and email address. |
| It flags accounts another team is handling | The Book is missing an exclusion | Fix the Book. See [Build a Book](/assignments/guides/build-a-book#add-your-exclusions). |
| The same user gets a new draft every run | There's no rule against repeating | Add "don't draft for a contact with a draft or sent message in the last 14 days". |
| Many accounts land in Not enough facts | The assignment can't reach the data it needs | Tell your Trig contact which data. A source may need connecting or sharing. |
| A result says "unknown, source not connected" | The assignment needs data Trig can't reach | Tell your Trig contact which data. A source may need connecting or sharing. |
| It doesn't use a source added since | It was planned before the source was added | Plan the assignment again. |

## Who to ask

| For | Ask |
| --- | --- |
| A field, table or tool that's missing | Your Trig contact, with the field name and where it lives |
| A Book or assignment that isn't behaving | Your Trig contact, with the name of the Book or assignment |
| Access for a colleague | Your Trig contact, with their name and work email |
